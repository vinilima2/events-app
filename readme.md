# EventsApp

![EventsApp Preview](events-app.gif)

## About the Project

**EventsApp** is an application for creating and managing events, allowing users to register events, add images, confirm attendance, and for administrators, view the guest list of confirmed and unconfirmed attendees.

## Features

- Create events with name, description, location, and date/time.
- Add images to the event.
- Screen to confirm attendance.
- Admin dashboard (password protected) to view the attendance confirmation list.
- Responsive interface for web and mobile.

## Technologies Used

**EventsApp** is built with the following technologies:

### Backend (API)
- Node.js framework for API
- ORM for database
- Relational database

### Frontend (Web)
- React framework for frontend
- UI styling

### Mobile
- Framework for mobile development with React Native
- Framework for mobile applications

### Build and Development
- TypeScript compiler for build and development mode

## How to Run the Project

### 1. Clone the Repository
```sh
  git clone https://github.com/vinilima2/events-app
  cd events-app
```

### 2. Set Up Project
```sh
  yarn install
```

### 3. Run Project
```sh
  yarn dev
```
